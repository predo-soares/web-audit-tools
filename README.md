# Audit Web Tools

Audit Web Tools is a macOS desktop toolkit for previewing and auditing websites across multiple device sizes. It combines synchronized device panes, runtime diagnostics, Page SEO and Lighthouse audits, and handoff bundles for AI coding agents.

## Highlights

- Preview a website across phone, tablet, and desktop viewports.
- Synchronize scrolling, clicks, forms, and navigation across linked panes.
- Inspect console and network evidence without opening DevTools.
- Run Page SEO and Lighthouse assessments against the active page.
- Share screenshots and sanitized evidence with a connected coding agent through MCP.

## Quick start

```bash
cd desktop
pnpm install
pnpm dev
```

The current release scope is macOS, with Apple Silicon as the first distribution target. See [desktop/README.md](desktop/README.md) for development and packaging details.
